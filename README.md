# K & A 🏡

A **K & A** é uma loja virtual dedicada à apresentação e comercialização de tapetes artesanais e itens decorativos. O projeto busca oferecer uma experiência de navegação moderna, elegante e responsiva, valorizando o design e os detalhes de cada produto.

## ✨ Funcionalidades

- Catálogo de produtos integrado ao Sanity CMS.
- Exibição dinâmica de produtos e categorias.
- Filtros e busca de produtos.
- Carrinho de compras.
- Carrossel de imagens.
- Layout responsivo para dispositivos móveis e computadores.
- Atalhos de contato e redes sociais.
- Animações e elementos visuais para uma experiência mais sofisticada.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Sanity CMS

## 🎯 Objetivo

Desenvolver uma experiência de comércio eletrônico visualmente atraente, funcional e adaptável a diferentes dispositivos, facilitando a apresentação dos produtos e a navegação dos clientes.

## 🚀 Execução local

1. Clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` com uma extensão como Live Server.
4. Configure a integração com o Sanity CMS para carregar os produtos publicados.
